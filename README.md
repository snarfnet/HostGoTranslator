# ホスト語翻訳機

SwiftUI製のローカル完結MVPです。普通の文章を、ホスト系キャラクターの口調に変換します。

## 含まれる機能

- 入力と翻訳
- キャラクター切替
- ローカルJSON辞書とテンプレ生成
- 22:00から5:00の深夜モード
- コピー、保存、シェア画像生成
- 広告視聴ガチャとSSRホスト解放
- UserDefaults保存
- AVFoundationとCoreHaptics用のフィードバック導線
- AdMob差し替え前提の広告プレースホルダー

## Xcode

`HostGoTranslator.xcodeproj`を開いて実行してください。iOS 18以上を想定しています。
